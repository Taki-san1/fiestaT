# Fiestas y Eventos Tarragona

Sistema web para registrar fiestas, calcular el valor a cobrar y consultar acumulados.
Hecho con HTML, CSS y JavaScript puro (sin dependencias). Los datos se guardan en `localStorage`.

## Uso local
Abre `index.html` en el navegador.

## Publicación
Se publica con GitHub Pages desde la rama `main` (carpeta raíz).
